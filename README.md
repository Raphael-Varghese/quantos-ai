# Quantos

Quantos is an artificial intelligence built fully from scratch in Python. It runs entirely in your terminal with a clean user interface. It checks your system RAM and changes its model size to fit your computer. It can also search the web and run Python code safely.

## Features

* **Built from Scratch:** Made using pure Python with no heavy pre-made frameworks.
* **Dynamic RAM Adaptation:** Checks your system memory and sizes the model to fit.
* **Terminal UI:** Fast and clean user interface inside your terminal.
* **Web Scraping:** Gathers live data from the internet.
* **Code Sandbox:** Runs Python code safely in an isolated space.

## Installation

Clone the repository to your local machine:

```bash
git clone https://github.com
cd quantos
```

I have made a all-around script that installs **all** your dependencies and **fully** runs the AI.

## Usage

Start the process by running:
```bash
bash ai.sh
```

## How It Works

1. Quantos scans your hardware when it starts up.
2. It measures your free RAM.
3. It loads the best matching parameters for your system.
4. You can type prompts, ask it to look up web pages, or run code directly in the terminal interface. It can code its own plugins. **DON'T WORRY**, there are sufficient safeguards and loops to ***ensure*** no problems.
